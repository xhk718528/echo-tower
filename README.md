# ⛰️ 回声之塔 (Echo Tower)

一个「适合上班摸鱼」的离线回合制网格 Roguelite,全部中文,可存档、可重复游玩,自带 Boss 键伪装。

## 运行
### 单机(最简单,离线可玩)
直接双击打开 `回声之塔.html` —— 这是一个单文件游戏,美术资源已内嵌为 base64,**无需任何后端**即可玩(进度存浏览器 localStorage)。

### 启用「云端存档 + 账号隔离」(推荐,可选)
游戏内建的数据库存档功能需要一个本地后端 + PostgreSQL:
1. 启动数据库: 在 `echo-tower-server` 目录执行 `docker compose up -d`(或用 `start.ps1`)。
2. 启动后端: 在 `echo-tower-server` 目录执行 `node server.js`(默认 http://localhost:4200)。
3. 浏览器打开 `http://localhost:4200/`,即可在游戏内「👤 登录/注册」,每个账号的存档互相隔离。

> 环境变量可覆盖后端连接: `PGHOST, PGPORT, PGUSER, PGPASSWORD, PGDATABASE, PORT`。

## 目录
- `回声之塔.html` —— 游戏本体(单文件,含全部美术与逻辑)。
- `assets/` —— 像素美术源文件(PNG)+ `README-美术规格.md`(美术规范)。
- `echo-tower-server/` —— 存档后端(Node.js + PostgreSQL,含账号鉴权与按用户隔离存档)。
- `_test.js / _render.js / _pxgen.js / _inject.js / _ts.js` —— 开发/回归/资源生成脚本(可重新生成美术与注入 base64)。

## 玩法特色
- 回合制网格战斗,敌人显示意图;职业:守卫/游侠/狂战士/法师。
- 装备系统(7 槽位、6 档稀有度、隐藏 T1~T7、套装 2/3/4/5/6 件套、词缀、强化 + 重铸)。
- 地图元素:宝箱/祭坛/商店/事件/楼梯/尖刺/岩浆/荆棘/篝火/水井/金币堆/传送门/钥匙/锁门/警钟/残破墙/宝箱怪。
- 主题随层数变化:地牢→洞窟→熔岩→王座;每层自动保证楼梯可达(不会卡关)。
- 塔魂强化、成就、装扮、每日挑战、回响(死后传承)。
